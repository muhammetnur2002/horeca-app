# Кликабельный макет Akyl: экраны и переходы

Макет на холсте: https://claude.ai/artifact/3WUTDc8xsa9nPmP2U87Mex. Ссылка закрыта, пока владелец не откроет к ней доступ. Ниже то же самое текстом: каждый экран и куда ведёт каждая кнопка.

Стиль взят из макета Figma «Akyl — две двери», тёмная тема. Лого — надпись «Akyl». Профиль сотрудника скопирован с экрана `04-profile`.

## Общий вход

**Лендинг**

- «Я сотрудник» → С1
- «Я владелец заведения» → З1

## Дверь сотрудника

**С1 Регистрация сотрудника** (почта, пароль, имя)

- «Создать профиль» → С2
- «←» → Лендинг

**С2 Профиль сотрудника** (фото, ID, ранг, специальность, опыт, фотоальбом)

- «Смотреть все» → С3
- «Ранг» → С4
- «Специальность» и «Опыт» → С8
- Иконка «Сменить вход» → Лендинг

**С3 Фотоальбом**

- «Добавить фото или видео»: видео больше 50 МБ не загружается
- «←» → С2

**С4 Звания:** Новичок → Работяга → Крутой → Мастер → Титан → Легенда. Пороги временные.

- «←» → С2

**С5 Мои чаты** (главная сотрудника)

- «Вакансии кухни» → С6
- «Кафе Север · 1 из 3» → С7

**С6 Вакансии кухни**

- «Откликнуться» → С7
- «←» → С5

**С7 Чат с заведением.** До одобрения можно отправить 3 сообщения, четвёртое не уходит. В макете счётчик работает.

- «←» → С5

**С8 Смены и стаж.** Полоска: меньше 180 дней — красная, 180–729 — жёлтая, от 730 — зелёная.

- «Добавить место работы» → С9

**С9 Новое место работы**

- «Сохранить» → С8
- «Отмена» → С8

**С10 Уведомления**

- «Кафе Север одобрил разговор» → С7
- «Новая вакансия кухни» → С6

Нижнее меню сотрудника: Главная (С5), Смены (С8), Профиль (С2), Уведомления (С10).

## Дверь заведения

**З1 Вход заведения**

- «Войти» → З3
- «Зарегистрировать заведение» → З2
- «Продолжить без аккаунта» → З4
- «←» → Лендинг

**З2 Регистрация заведения** (почта, название, точка)

- «Зарегистрировать заведение» → З4

**З3 PIN.** 5 ошибок → 30 секунд замка. В макете клавиатура работает.

- «Войти» → З4
- «Забыли PIN?» → З1

**З4 Главная заведения:** карточка «Сегодня» и одна оранжевая главная кнопка.

- «Сделать заявку» → З5
- «Приёмка» → З7
- «Инвентаризация» → З8
- «Закрытие смены» → З9
- «Остатки» → З10
- «Аналитика» → З11
- «iiko» → З12
- «Вакансии и кандидаты» → З13

**З5 Заявка** (строки: товар, количество, единица)

- «Сохранить заявку» → З6

**З6 Отправка заявки**

- WhatsApp, Telegram, PDF
- «Готово» → З4

**З7 Приёмка:** как заказали, меньше, не привезли, лишнее.

- «Завершить приёмку» → З10

**З8 Инвентаризация**

- «Сохранить пересчёт» → З10

**З9 Закрытие смены**

- «Закрыть смену» → З4

**З10 Остатки:** много, мало, плохо, ровно.

- «Обновить остатки» → З8

**З11 Аналитика** (только администратор)

- «Таблица остатков» → З10

**З12 iiko.** Если iiko не ответила, числа не подставляются.

- «Подтянуть расход»

**З13 Вакансии и кандидаты**

- «Новая вакансия» → З14
- «Кандидаты кухни» → З15

**З14 Новая вакансия.** Сфера берётся из специальности.

- «Опубликовать» → З13
- «Отмена» → З13

**З15 Кандидаты кухни**

- «Написать первым» → З18

**З16 Чаты заведения**

- «Аня Ковалёва · ждёт одобрения» → З17
- «Канал кандидатов» → З15
- «Пётр Смирнов» → З18

**З17 Одобрение**

- «Одобрить разговор» → З18
- «Отклонить» → З16

**З18 Чат с кандидатом:** у владельца лимита нет.

- «←» → З16

**З19 История** (заявки, пересчёты, смены)

**З20 Настройки**

- «Доступ людей» → З21
- «Сменить вход» → Лендинг

**З21 Доступ в заведение.** Выдаёт только владелец; разделы заявки, инвентаризация, смена, склад, история.

- «←» → З20

Нижнее меню заведения: Главная (З4), Чаты (З16), История (З19), Настройки (З20).
